# Таймер сна: плитка в шторке + расписание

## Что умеет

**Плитка «Таймер сна» в шторке.** Нажал, и через N минут (по умолчанию 30, меняется в приложении) остановится любое аудио: музыка, видео, подкасты. Нажал ещё раз, и таймер отменится. Долгое нажатие на плитку открывает приложение.

**Расписание.** Правила вида «каждый день с 08:00 до 14:00 включать режим без звука». Доступные действия:

| Действие | Что делает | Нужен доступ «Не беспокоить» |
|---|---|---|
| Режим без звука | выключает звонок и вибрацию, в конце возвращает как было | да |
| Только вибрация | переводит звонок в вибрацию | на всякий случай да |
| Не беспокоить | включает DND (по вашим настройкам DND), в конце возвращает | да |
| Остановить всё аудио | в заданное время ставит всё на паузу | нет |

Что **нельзя** сделать обычным приложением на современном Android: включать и выключать Wi-Fi, Bluetooth, мобильные данные и авиарежим. Эти переключатели доступны только системе.

## Сборка. Способ 1: GitHub Actions (ничего не нужно ставить на ПК)

1. Зарегистрируйтесь на github.com.
2. Нажмите **+** справа вверху, затем **New repository**. Имя любое, например `sleeptile`, тип **Private**. Нажмите **Create repository**.
3. Распакуйте архив на ПК. На странице репозитория нажмите **uploading an existing file** и перетащите в окно **всё содержимое** папки `SleepTile`: `app`, `gradle`, `.github`, `build.gradle.kts` и остальное. Нажмите **Commit changes**.
4. Проверьте, что в репозитории появилась папка `.github`. Если её нет (скрытые папки иногда не перетаскиваются), нажмите **Add file → Create new file**, в имени напишите `.github/workflows/build.yml` (слэши создадут папки), вставьте туда содержимое файла `build.yml` из архива и нажмите **Commit**.
5. Откройте вкладку **Actions**. Если появится кнопка про включение workflow, нажмите её. Сборка стартует сама после загрузки файлов. Иначе: слева **Build APK → Run workflow**.
6. Через 3–6 минут появится зелёная галочка. Откройте этот запуск, внизу в разделе **Artifacts** скачайте `SleepTile-apk`. Внутри zip лежит `app-debug.apk`.
7. Передайте APK на телефон (Telegram «Избранное», кабель, облако).

Красный крестик значит, что сборка упала. Откройте запуск, нажмите на красный шаг, скопируйте последние ~40 строк лога и пришлите их мне.

## Сборка. Способ 2: Android Studio

1. Установите Android Studio (developer.android.com/studio).
2. **File → Open** и выберите папку `SleepTile`. Подождите, пока закончится Gradle Sync (первый раз скачивает несколько сотен МБ).
3. Меню **Build → Build Bundle(s) / APK(s) → Build APK(s)**. Справа внизу появится ссылка **locate**. APK лежит в `app/build/outputs/apk/debug/app-debug.apk`.
4. Либо включите на телефоне «Отладку по USB», подключите его кабелем и нажмите зелёный ▶ (Run). Приложение установится само.

Обновление приложения: APK из GitHub Actions каждый раз подписывается новым временным ключом, поэтому новую версию придётся ставить, удалив старую (правила сбросятся). При сборке в Android Studio на одном и том же ПК ключ один и тот же, и обновление ставится поверх.

## Установка и настройка на iQOO Neo 10 (Origin OS)

1. Откройте APK на телефоне и разрешите установку из этого источника. Если Origin OS предупреждает о неизвестном приложении, выберите «Всё равно установить».
2. Откройте приложение «Таймер сна». Ползунком выберите время по нажатию на плитку.
3. Нажмите **«Добавить плитку в шторку»** и подтвердите. Если окна нет, потяните шторку, нажмите значок ✎ и перетащите плитку «Таймер сна» в верхние ряды.
4. Для правил с «без звука», вибрацией и DND нажмите **«Выдать доступ»**, найдите в списке «Таймер сна» и включите.
5. Чтобы система не убивала приложение (иначе будильники могут не сработать):
   - Нажмите **«Открыть настройки приложения»**. Включите **автозапуск** и в разделе батареи выберите **работу без ограничений / разрешить фоновую активность**. Названия пунктов на Origin OS могут отличаться.
   - В списке недавних приложений **зафиксируйте** карточку «Таймер сна» (на vivo обычно тянут карточку вниз или нажимают значок замка). Смахнутое из списка приложение Origin OS может остановить вместе с его будильниками.
6. Проверка: включите музыку, создайте правило «Остановить всё аудио» на ближайшую минуту и дождитесь паузы. Потом можно проверить плитку: запустите её на 5 минут.

## Если что-то не работает

- **Плитка нажимается, но музыка не останавливается.** Проверьте пункт 5 (автозапуск, батарея, замок). Если не помогло, напишите, в каком плеере это происходит.
- **«Без звука» не включается.** Скорее всего, не выдан доступ «Не беспокоить» (пункт 4).
- **Правило не сработало в нужное время.** Та же причина, что в первом пункте.
